Sales Performance Dashboard:

📊 Project Overview:

This project presents an interactive Sales Performance Dashboard built using Excel. 
The dashboard analyzes regional and category-wise sales performance and profitability.

🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Design
- Basic Data Cleaning

📈 KPIs
- Total Sales
- Total Profit
- Total Quantity
- Profit Margin %

🔎 Key Insights
- West region generates the highest sales.
- Office Supplies is the most profitable category.
- Furniture in Central region shows negative profit.
- High sales do not always result in high profit.
